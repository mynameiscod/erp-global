# global-erp (codename)

AI-native, configurable, multi-tenant cloud ERP platform: one kernel for any industry, country,
language and business model, configured through Industry Packs, Country Packs, Language Packs,
metadata and extensions.

**Status:** Phase 0 architecture accepted (2026-09-24). Phase 1 (platform foundation) in progress.

No commercial product name has been chosen yet; `global-erp` is an internal codename, and
branding is configuration (see [ADR-0015](docs/adr/0015-naming-and-branding.md)).

Start with [docs/README.md](docs/README.md).
